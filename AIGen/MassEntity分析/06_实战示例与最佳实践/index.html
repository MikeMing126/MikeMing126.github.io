基于虚幻引擎 5.7 源码和官方示例

一、自定义 Fragment

1.1 基本 Fragment 定义

要点：

  • Fragment 必须继承自 FMassFragment
  • Tag 必须继承自 FMassTag，且不应包含任何成员变量
  • 所有 Fragment 都必须有 GENERATED_BODY() 宏
  • 成员变量建议使用 UPROPERTY() 标记（支持反射和序列化）
  • Fragment 必须是可平凡复制的（或通过 Traits 显式选择退出）

七、最佳实践

7.1 性能优化

  1. 使用 Tag 替代 Boolean Fragment

  2. 使用 ConstSharedFragment 共享不可变配置

  3. 使用 ChunkFragment 管理 Chunk 级别状态

  4. 避免在 Processor 中频繁调用 Defer()

  5. 使用并行执行

7.2 架构建议

  1. Processor 保持无状态：所有数据存储在 Fragment 中，Processor 不应有成员变量存储状态
  2. 使用 Trait 组合实体：通过编辑器配置而非硬编码
  3. 最小化 Archetype 数量：避免动态频繁添加/移除 Fragment
  4. 使用 Observer 替代轮询：监听 Fragment 添加/移除，而非每帧检查
  5. 合理使用处理阶段：PrePhysics 做逻辑，PostPhysics 做表现

7.3 调试技巧

  1. 使用 Mass Entity Debugger：Window → Developer Tools → Mass Debugger
  2. 检查 Archetype 数量：过多 Archetype 会降低 Query 缓存效率
  3. 使用 Mass Insights：通过 Unreal Insights 分析 Processor 执行时间
  4. 检查 Fragment 大小：过大的 Fragment 会降低每 Chunk 的实体数量

7.4 常见陷阱

  1. Fragment 中使用非平凡类型

  2. 在 Processor 执行期间修改实体结构

  3. 忘记注册 Query

  4. 在错误的执行阶段做操作
