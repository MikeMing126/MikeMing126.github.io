04 - Data Layer 系统详解

基于 UE 5.7 源码 Engine/Source/Runtime/Engine/Public/WorldPartition/DataLayer/

一、Data Layer 概述

Data Layer（数据层）是 World Partition 的逻辑分层系统。它允许开发者将世界内容按逻辑分组，并在运行时动态控制这些分组的加载/卸载状态。

1.1 典型应用场景

场景 示例
任务系统 任务 A 完成后加载任务 B 的场景内容
季节系统 夏天/冬天场景切换
日夜系统 白天/夜晚不同的 NPC 和物件
难度选择 困难模式下增加额外的障碍物
DLC 内容 安装 DLC 后加载额外内容
平台差异化 高端平台加载额外细节

7.2 Cell 有效状态计算

计算逻辑：

  1. 如果 Cell 没有 Data Layer → 始终 Activated
  2. 如果有 Data Layer → 查询每个 Data Layer 的有效状态
  3. 根据 DataLayersLogicOperator（Or/And）组合结果
  4. 如果所有 Data Layer 都是 Activated → Cell 可以 Activated
  5. 如果任一 Data Layer 是 Unloaded → Cell 必须 Unloaded

7.3 FWorldPartitionStreamingContext

StreamingContext 在每次流式更新时创建，缓存了当前 Data Layer 的有效状态，避免重复计算。
