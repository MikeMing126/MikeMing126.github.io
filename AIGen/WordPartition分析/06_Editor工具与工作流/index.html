三、OFPA（One File Per Actor）

3.1 概念

OFPA 是 World Partition 的核心编辑器机制。每个 Actor 存储在独立的包文件中，而非全部放在一个关卡文件中。

3.2 优势

优势 说明
版本控制友好 多人编辑同一地图时，只锁定修改的 Actor 文件
按需加载 编辑器只需加载当前区域的 Actor
外部引用 Actor 可以被其他关卡引用
增量保存 只保存修改的 Actor
