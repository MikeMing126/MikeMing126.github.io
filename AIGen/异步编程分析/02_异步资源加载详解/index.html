7. 与 Unity Addressables 对比

维度 UE5 FStreamableManager Unity Addressables
核心概念 FSoftObjectPath + FStreamableHandle AssetReference + AsyncOperationHandle
异步加载 RequestAsyncLoad() Addressables.LoadAssetAsync<T>()
进度追踪 Handle->GetProgress() handle.PercentComplete
取消加载 Handle->CancelHandle() Addressables.Release(handle)
批量加载 传 TArray 多个 LoadAssetAsync 或 LoadAssetsAsync
组合等待 CreateCombinedHandle() Addressables.DownloadDependencies()
内存管理 ReleaseHandle() Addressables.Release()
优先级 TAsyncLoadPriority (int32) PackageManager.SetWebRequestPriority
引用类型 TSoftObjectPtr AssetReferenceT
配置 DataAsset + PrimaryAssetLabel AddressableAssetGroup

关键差异：

  1. UE5 内置集成：FStreamableManager 是引擎核心模块的一部分，不需要额外安装
  2. GC 集成：FStreamableManager 继承自 FGCObject，与UE的垃圾回收系统深度集成
  3. IoStore 支持：UE5 的异步加载与 IoStore 文件系统紧密集成，支持 OnDemand 下载
  4. 编辑器支持：软引用可以在编辑器中直接编辑和检查
