1. UE5 的协程现状

1.1 C++20 协程支持情况

截至 UE 5.7.4 版本，引擎不支持 C++20 协程（co_await / co_return / co_yield）。

在引擎源码中搜索所有 C++20 协程关键字，均未找到相关实现。UE5 的”协程”概念主要体现在：

  • 蓝图 Latent Action：通过 FPendingLatentAction 实现的每帧轮询式延迟操作
  • Verse 语言协程：仅存在于 Verse 脚本语言编译器中，非 C++ 层面
  • TFuture/TPromise：函数式异步结果传递，类似 C# 的 Task<T>
  • 实验性 TAwaitableTask：提供 Await() 方法的可等待任务

7.4 优缺点总结

TFuture/TPromise 模式的优点：

  • 类型安全的异步结果传递
  • 支持链式调用（Then/Next）
  • 与 Async() 函数无缝集成
  • 支持共享 Future（TSharedFuture）

TFuture/TPromise 模式的缺点：

  • 没有 async/await 语法糖，代码可读性不如 C# 的 async/await
  • 深层嵌套链式调用仍然较难阅读
  • 没有 built-in 的异常传播机制
  • 回调地狱问题（可通过 Next/Then 缓解）

蓝图 Latent Action 的优点：

  • 蓝图中直观易用
  • 自动生命周期管理
  • 与蓝图编辑器深度集成

蓝图 Latent Action 的缺点：

  • 仅限蓝图使用
  • 每帧轮询式检查（非事件驱动）
  • 需要手动管理 UUID 避免重复
