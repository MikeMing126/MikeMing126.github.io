虚幻引擎核心架构

主要对底层的Engine，GameInstance,FWorldContext,World,Level来做一个详细的说明

先来一个Gameplay的大框架图。来总体理解虚幻的这套游戏框架是怎么样的。

UEngine

本质

UEngine 本身含有纯虚函数，是一个抽象基类，不可直接实例化。全局通过 GEngine 变量访问唯一的引擎实例。

继承关系：

核心数据成员

WorldList 是 UEngine 级别的管理容器，用于追踪不同 UWorld 的状态。

实例情况

状态 Engine 实例 说明
开发状态（编辑器） 1 个 UEditorEngine 编辑器启动时创建，PIE 也由它管理
打包状态（运行时） 1 个 UGameEngine 游戏启动时创建

关键澄清：开发状态下不会同时存在 EditorEngine 和 GameEngine。编辑器模式下只有 UEditorEngine，PIE 是由 EditorEngine 通过创建新的 WorldContext 和 GameInstance 来实现的。

生命周期

UEngine 的生命周期与进程相同，从启动到退出始终存在唯一的 GEngine 实例。

UGameInstance

本质

UGameInstance 是游戏会话的最高层管理者，生命周期跨越多个关卡。适合存储跨关卡数据（如分数、玩家状态、全局配置等）。

实例情况

状态 GameInstance 数量 说明
开发状态 0~N 编辑器本身没有 GameInstance；每个 PIE 实例创建一个；PIE 多开则存在多个
打包状态 1 一个进程对应一个 GameInstance（无论 Client 还是 Server）

关键关系

  • FWorldContext::OwningGameInstance — WorldContext 持有 GameInstance 的引用
  • UWorld::OwningGameInstance — UWorld 也直接持有 GameInstance 的引用
  • 在GameEngine的情况下，GameEngine也持有GameInstance的引用

FWorldContext（世界上下文）

本质

FWorldContext 是一个 C++ 结构体（非 UObject），是 UEngine 用来追踪不同 UWorld 状态的容器。

“WorldContexts can be thought of as a track. By default we have 1 track that we load and unload levels on. Adding a second context is adding a second track; another track of progression for worlds to live on.”

核心成员

世界类型（EWorldType）

类型 说明
Game 游戏世界
Editor 编辑器中的世界
PIE Play In Editor 世界
EditorPreview 编辑器预览世界

对应关系

状态 WorldContext 数量 说明
开发状态 1~N EditorEngine 持有：一个用于 EditorWorld，每个 PIE 实例一个
打包状态 1 GameEngine 持有一个 WorldContext

关键特性：WorldContext 与 GameInstance 是 1:1 绑定的。在 GameInstance 的生命周期中，WorldContext 始终只有一个，不会销毁和重建。关卡切换时，WorldContext 只是将其内部的 ThisCurrentWorld 指针从旧 World 改为指向新 World。

编辑器本身比较特殊，其有FWorldContext，但不会有GameInstance。

UWorld（世界）

本质

UWorld 是游戏世界的运行时表示，包含关卡、Actor、游戏规则（GameMode）等。

实例情况

状态 UWorld 数量 说明
开发状态 可多个 编辑器有 EditorWorld，每个 PIE 实例有 PIE World，可同时存在
打包状态 同一时间 1 个 关卡切换时旧 World 销毁、新 World 创建

生命周期

  • 创建时机：加载地图（LoadMap）时实例化
  • 销毁时机：ServerTravel / ClientTravel 时，旧 UWorld 被标记为待垃圾回收（GC），新的 UWorld 被实例化并赋值给 WorldContext
  • 特点：同一时间只有一个 UWorld，但在 GameInstance 的整个生命周期中可能会有多个 UWorld 先后被创建和销毁

ULevel（关卡）

本质

Level 是 World 之下的子单元。一个 UWorld 包含一个 PersistentLevel 和可选的多个 Sub-Levels。
