反射 —— FProperty与FField

发表于2026-04-20|更新于2026-04-21|UE
|总字数:1.2k|阅读时长:4分钟|浏览量:

要理解FProperty,FField,以及对应的UField等一系列概念，还得从反射来说起。

反射系统核心概念

关于反射的作用，可以看到这篇文章

反射系统 Reflection System

C++ 原生类型在运行时默认没有反射能力，无法知道一个类有哪些成员、名称、类型、内存偏移量等。UE 通过 FProperty 系统为 C++ 类型添加了运行时反射。

关键反射文件

类 源文件
FField Engine/Source/Runtime/CoreUObject/Public/UObject/Field.h
FProperty Engine/Source/Runtime/CoreUObject/Public/UObject/UnrealType.h
UField Engine/Source/Runtime/CoreUObject/Public/UObject/Class.h
UProperty（旧版，已废弃） Engine/Source/Runtime/CoreUObject/Public/UObject/UnrealTypePrivate.h
UFunction Class.h → UStruct → UField → UObject

FField 设计分析

简而言之：反射数据。

从 UProperty 到 FProperty

在早期版本中，反射类型都基于 UObject：

每一个属性描述对象本身就是一个 UObject，带来了巨大开销：每个 UObject 都有 GC 开销、完整的 UObject 基础设施（路径名、加载器、对象标志等），一个类几十个属性每个都是 UObject，非常浪费。

FField 是一个轻量级的 UObject 替代品，模拟了 UObject 的关键接口（Serialize、PostLoad、AddReferencedObjects 等），但不继承 UObject：

  • ❌ 不参与 GC
  • ❌ 不在对象数组中注册
  • ❌ 没有完整的 UObject 开销
  • ✅ 通过 FMemory::Malloc/FMemory::Free 手动管理内存
  • ✅ 保留了反射所需的核心能力

部分遗留内容：

这段注释说明 FField 是一个过渡方案，为了方便从 UProperty 迁移到 FProperty 而模拟了 UObject 接口。

FProperty

所有属性描述的基类。

FProperty 是 FField 目前唯一的直接子类，但 FField 独立存在有三个重要原因：

  1. 未来扩展性：FField 设计意图是作为所有反射数据对象的基类，不仅是属性。将来可能会有函数描述、枚举描述等也继承 FField
  2. 与 UField/UObject 体系的对称设计：FField 对应 UField，FProperty 对应 UProperty，便于理解和迁移
  3. FFieldVariant 桥接两个体系：需要 FField 作为独立基类来支持联合体设计

而UFunction、UEnum等类型，目前还是UField的子类。

FFieldVariant 桥接机制

FFieldVariant 可持有 FField* 或 UObject*，通过最低有效位（bit 0）区分类型。

FField 的 Owner 成员就是 FFieldVariant 类型，所以一个 FProperty 的拥有者可以是 UClass（一个 UObject），也可以是另一个 FField。

注释原文：”DO NOT ABUSE. IDEALLY THIS SHOULD ONLY BE FFIELD INTERNAL STRUCTURE FOR HOLDING A POINTER TO THE OWNER OF AN FFIELD.” —— 表明这是一种过渡设计。

其他说明

反射系统的核心价值

有了 FProperty 系统，UE 实现了以下核心能力：

  • 编辑器集成：Details 面板可以自动显示所有 UPROPERTY
  • 蓝图交互：蓝图可以访问 C++ 属性
  • 序列化：自动保存/加载属性
  • 网络复制：自动同步属性到客户端
  • 垃圾回收：自动追踪 UObject 引用

FProperty 详解

核心定义

FProperty 存储的关键信息：

信息 说明
NamePrivate 属性名称（如 “Health”）
Offset_Internal 在类内存布局中的偏移量
ElementSize 属性的大小（字节）
PropertyFlags 属性标志（如 EditAnywhere, BlueprintReadWrite）
ArrayDim 如果是数组，存储数组维度

层次分类

UE 为不同类型创建了不同的 Property 类：

  • 基础类型：FIntProperty、FFloatProperty、FBoolProperty、FNameProperty
  • 复合类型：FStructProperty、FObjectProperty、FArrayProperty、FMapProperty
  • 特殊类型：FEnumProperty、FDelegateProperty、FInterfaceProperty
